# 碎面 · AARON.HUB — 主页原型 v0.1

一个立体主义（分析立体主义 1910–12）拼贴风格的个人主页门面。单文件、零依赖、直接双击打开。

- 主文件：`index.html`（自包含 CSS / JS，约 70 KB）
- 预览图：`preview-1440.png`（1440×900 定稿截图）

## 为什么这样排

不做「大标题 + 三张卡片」。页面是一张拼贴桌：四块不等宽的纸/墨面 + 一块纸片，十二栏网格故意被切得不均匀。

| 区域 | 作用 | 材质 |
|---|---|---|
| 00 AARON | 字标 / 自我介绍 | 墨黑 + 错版红字 |
| 01 项目与作品 | 对外展示（公开） | 暗红漆面 + 幽灵字 |
| 02 我的服务 | 完全个人用（内网） | 骨白纸 + 橡皮章 |
| 03 设备探针 | 三节点状态 | 墨黑 + 实时火花线（演示） |
| 04 此刻 | 现在在做什么 | 墨黑 |
| 05 资料库 / 06 联系 | 写作与联系 | 开放格，只有发丝线 |
| 底部索引 | 六个入口 + 本地时钟 | 深色台座 |

字体：Bahnschrift（字标/数字）／宋体（中文标题）／等宽（数据标签）。
色板：`#090807` 墨、`#7C1219` 血、`#A51F26` 绯、`#E4D6C1` 纸、`#A8814E` 黄铜。

## 交互

- **⌘K / Ctrl+K**：命令面板（可过滤，↑↓ + ↵）
- 点击任一平面：右侧「碎片抽屉」，底部有 01–06 快速切换
- **ESC** 关闭；右上可切「颗粒 / 动效 / 辅助线」（localStorage 记忆）
- 探针每 2.6s 随机游走一次；时钟走真实本地时间（Asia/Shanghai）
- 全站响应式：<980px 折为单列，<620px 收紧控件

## 改数据的地方

`<script>` 顶部：

- `NODES` — 三个节点的名字、角色、基准数值
- `PROJECTS` — 项目列表（首页显示前 3 条，抽屉显示全部）
- `CONTENT` — 六个抽屉的 HTML 内容（含设计笔记与待定项表）

探针目前是**前端模拟**（`bumpNode`），页面上已明确标注 DEMO。
接真实数据的建议：每台机器暴露 `GET /probe` 返回 cpu/mem/temp/disk，前端 5s 轮询，失败时整块置灰。

## 验证

在 Chromium 中实测：1440×900 / 1600×1000 / 430×932 三档，无横向溢出；抽屉、命令面板、ESC、辅助线、时钟、火花线均正常；无控制台报错。
